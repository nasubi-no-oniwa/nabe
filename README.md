# なべなべすくい

野菜と鶏肉を点線どおりに切って、鍋からおたまですくうゲーム。

- 具材を4回えらんで、点線を指でなぞって切る
- 鍋の具はだんだん煮える（生 → キラキラ → 煮すぎ → まっ黒）。キラキラのときにすくうと強い
- 鍋を指でなぞっておたまですくう。3回まで。時間制限はないが、全部まっ黒になったら終わり
- すくった具はすくった順に鍋の手前に並び、最後に1こずつ計算（野菜は＋、肉は×、左から順）。計算はとばせる
- 3回すくった点数で、鍋ごと（白湯とり鍋・野菜よせ鍋・激辛鍋）のランキング
